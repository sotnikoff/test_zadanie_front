# Мини-Кадрика

Интерактивный прототип генерации стихотворений с учётом внутренних единиц. Сейчас работает локально в браузере; Django, PostgreSQL и настоящий AI — следующий этап.

[Демо](https://mini-kadrika.vercel.app/) · [Репозиторий](https://github.com/sotnikoff/test_zadanie_front)

## Как запустить

Нужны Node.js 24 и npm. В папке проекта:

```sh
npm ci
cp .env.example .env
npm run dev
```

Откройте адрес из терминала, обычно http://localhost:5173. Для прототипа backend и API-ключи не нужны.

## Тестовые аккаунты

Пароль для всех — `demo1234`. Кнопки на странице входа заполняют данные аккаунта.

| Пользователь | Email | Начальный баланс |
| --- | --- | ---: |
| Анна | user@example.com | 130 |
| Михаил | user2@example.com | 10 |
| Алексей | user3@example.com | 0 |

Генерация стоит 10 неделимых единиц. Результат и новый баланс сохраняются после обновления страницы. Кнопка «Сбросить демо-данные» на логине после подтверждения восстанавливает начальные балансы и историю всех аккаунтов.

Стихи собраны из заготовок, авторизация и списания имитируются. Используйте одну вкладку; LocalStorage не обеспечивает серверную безопасность и конкурентный учёт. Искусственных задержек и поллинга нет.
