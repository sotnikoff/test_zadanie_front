# Мини-Кадрика

Интерактивный frontend-прототип для согласования MVP сервиса генерации стихотворений и учёта внутренних единиц. Backend и реальные AI API не подключены.

## Запуск

Требуется Node.js 22.13+ в ветке 22, 24.x или 26+ (проверено на Node.js 26) и npm.

```sh
npm ci
cp .env.example .env
npm run dev
```

Открыть http://localhost:5173. Если порт занят, Vite напечатает другой адрес. Для воспроизводимой установки используется package-lock.json.

```sh
npm run lint
npm test
npm run typecheck
npm run build
```

Production-файлы находятся в `dist`. При размещении на статическом хостинге настройте SPA fallback на `index.html` для React Router. Публикация в рамках этой реализации не выполнялась.

## Демонстрационные аккаунты

Панель Demo Tools убрана из интерфейса по последнему согласованию. Локальные сценарии сбоя, возврата и переключения сохранены в локальном API и тестах. Для смены аккаунта используйте выход и страницу входа. Верхняя панель закреплена при прокрутке.

| Email             | Пароль   | Начальный баланс |
| ----------------- | -------- | ---------------- |
| user@example.com  | demo1234 | 130              |
| user2@example.com | demo1234 | 10               |
| user3@example.com | demo1234 | 0                |

Начальные балансы включают демонстрационные начисления, списания и возвраты. На странице входа кнопки заполняют email и пароль; вход подтверждается отдельной кнопкой.

## Конфигурация

| Переменная        | По умолчанию                 | Назначение                |
| ----------------- | ---------------------------- | ------------------------- |
| VITE_DATA_SOURCE  | local                        | local или http            |
| VITE_API_BASE_URL | http://localhost:8000/api/v1 | Base URL будущего backend |

Для подключения REST измените `VITE_DATA_SOURCE=http`, задайте адрес API и перезапустите Vite (для production пересоберите приложение). `src/api/index.ts` выбирает одну реализацию общего API: локальную или HTTP. Страницы менять не требуется. В HTTP-режиме локальное хранилище не инициализируется и Demo Tools не отображаются. Без реализованного backend этот режим покажет ошибку соединения — это не запасной локальный режим.

## Реализовано

Закрытая авторизация, личный кабинет, генерация, история и копирование, личный баланс и операции, единое версионируемое локальное хранилище, подготовленный HTTP-слой. Локальные запросы и генерация выполняются сразу, без искусственных задержек и фоновых таймеров. Управление пользователями, роли и пополнение баланса исключены из проекта.

Схема хранения v2 автоматически принимает прежнюю v1: сохраняет аккаунты, сессии, балансы и историю, убирает роли и служебные данные ручных начислений. Старые аккаунты остаются обычными пользовательскими; новые демо-данные содержат Анну, Михаила и Алексея. Алексей (user3@example.com) имеет нулевой баланс и пустую историю; он автоматически добавляется в существующее хранилище при перезагрузке без сброса других аккаунтов.

Технологии: React, TypeScript strict, Vite, React Router, TanStack Query, Tailwind CSS, локальные компоненты shadcn/ui на Radix (кнопка; меню аккаунта на Radix), Lucide, Vitest. Radix обеспечивает фокус и клавиатурное поведение меню, CVA/clsx/tailwind-merge обслуживают компоненты shadcn.

ESLint проверяет TypeScript и правила React Hooks; `npm run lint` завершается ошибкой при любом предупреждении. Конфигурация находится в `eslint.config.js`.

## Где смотреть код

- `src/api/local.ts` — вход, генерация, списание, возврат, история. Все действия эмуляции в одном файле.
- `src/api/storage.ts` — загрузка и сохранение JSON в LocalStorage.
- `src/api/demo-data.ts` — демо-аккаунты и готовые стихотворения.
- `src/api/types.ts` — общие типы и один интерфейс Api.
- `src/api/http.ts` — реализация тех же методов через fetch.
- `src/api/index.ts` — выбор local/http по конфигурации.

Из React вызывается `const api = useApi()`, затем `api.login()`, `api.generate()`, `api.getWallet()` и другие обычные методы. Страницы находятся в `src/pages`, hooks — в `src/hooks`. Порты, классы адаптеров и отдельные архитектурные слои удалены. Подробный путь одного запроса — в [описании устройства проекта](docs/frontend-architecture.md).

## Важные ограничения

LocalStorage под ключом `mini-kadrika:db` содержит все демонстрационные данные, включая пароли. Они не защищены от владельца браузера. Используйте один экземпляр приложения в одной вкладке: параллельная работа вкладок и настоящая многопользовательская конкурентность не поддерживаются. Связанное состояние сохраняется одной записью, что не является ACID-транзакцией.

Mock AI выбирает подготовленные четверостишия. Тема служит заголовком, пожелания сохраняются, но не интерпретируются. Создание пользователей и пополнение баланса через приложение недоступны. Результат, баланс и операции сохраняются вместе; незавершённые записи от старых версий получают FAILED и единственный возврат при запуске. Копирование требует поддержки Clipboard API и разрешений браузера.

Тесты локального API не подтверждают безопасность, конкурентность или транзакционную целостность будущего backend. Интеграция с реальным backend не тестировалась.
