# Мини-Кадрика

Интерактивный frontend-прототип для согласования MVP сервиса генерации стихотворений и учёта внутренних единиц. Backend и реальные AI API не подключены.

## Запуск

Требуется Node.js 22.12+ в ветке 22, 24.x или 26+ (проверено на Node.js 26) и npm.

```sh
npm ci
cp .env.example .env
npm run dev
```

Открыть http://localhost:5173. Если порт занят, Vite напечатает другой адрес. Для воспроизводимой установки используется package-lock.json.

```sh
npm test
npm run typecheck
npm run build
```

Production-файлы находятся в `dist`. При размещении на статическом хостинге настройте SPA fallback на `index.html` для React Router. Публикация в рамках этой реализации не выполнялась.

## Демонстрационные аккаунты

Панель Demo Tools убрана из интерфейса по последнему согласованию. Локальные сценарии сбоя, возврата и переключения сохранены в адаптерах и тестах. Для смены аккаунта используйте выход и страницу входа. Верхняя панель закреплена при прокрутке.

| Email             | Пароль   | Роль  | Начальный баланс |
| ----------------- | -------- | ----- | ---------------- |
| admin@example.com | demo1234 | ADMIN | 130              |
| user@example.com  | demo1234 | USER  | 130              |
| user2@example.com | demo1234 | USER  | 10               |

Начальные балансы включают демонстрационные начисления, списания и возвраты. На странице входа кнопки заполняют email и пароль; вход подтверждается отдельной кнопкой.

## Конфигурация

| Переменная        | По умолчанию                 | Назначение                |
| ----------------- | ---------------------------- | ------------------------- |
| VITE_DATA_SOURCE  | local                        | local или http            |
| VITE_API_BASE_URL | http://localhost:8000/api/v1 | Base URL будущего backend |

Для подключения REST измените `VITE_DATA_SOURCE=http`, задайте адрес API и перезапустите Vite (для production пересоберите приложение). Composition Root выбирает все четыре адаптера централизованно. Страницы менять не требуется. В HTTP-режиме локальное хранилище не инициализируется и Demo Tools не отображаются. Без реализованного backend этот режим покажет ошибку соединения — это не запасной локальный режим.

## Реализовано

Закрытая авторизация, роли, личный кабинет, генерация с отслеживанием статуса, история и копирование, баланс и операции, административные списки и фильтры, создание пользователей и начисление, Demo Tools, единое версионируемое локальное хранилище, подготовленный HTTP-слой.

Технологии: React, TypeScript strict, Vite, React Router, TanStack Query, Tailwind CSS, локальные компоненты shadcn/ui на Radix (кнопка и диалог; меню аккаунта на Radix), Lucide, Vitest. Radix обеспечивает фокус и клавиатурное поведение диалогов/меню, CVA/clsx/tailwind-merge обслуживают компоненты shadcn.

## Важные ограничения

LocalStorage под ключом `mini-kadrika:db` содержит все демонстрационные данные, включая пароли. Они не защищены от владельца браузера. Используйте один экземпляр приложения в одной вкладке: параллельная работа вкладок и настоящая многопользовательская конкурентность не поддерживаются. Связанное состояние сохраняется одной записью, что не является ACID-транзакцией.

Mock AI выбирает подготовленные четверостишия. Тема служит заголовком, пожелания сохраняются, но не интерпретируются. Новые пользователи получают роль USER и нулевой баланс. Перезагрузка во время генерации приводит к FAILED и единственному возврату. Копирование требует поддержки Clipboard API и разрешений браузера.

Тесты локальных адаптеров не подтверждают безопасность, конкурентность или транзакционную целостность будущего backend. Интеграция с реальным backend не тестировалась.
