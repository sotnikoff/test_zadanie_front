# Ограничения и фактическая проверка

Авторизация, генерация контента, многопользовательская работа и финансовые операции — демонстрационные имитации. Все данные доступны владельцу браузера, включая демонстрационные пароли. Route Guard и локальные проверки не обеспечивают production-безопасность.

Хранилище сохраняет единый снимок связанных изменений, но LocalStorage не даёт настоящих ACID-транзакций, блокировок или конкурентной многопользовательской работы. Поддерживается одна активная вкладка; параллельные вкладки могут перезаписывать данные. При недоступности/переполнении хранилища приложение сообщает об ошибке. Если запись результата таймером не удалась, незавершённая запись восстанавливается с компенсацией при следующем запуске после устранения проблемы хранилища.

Mock AI не интерпретирует пожелания, не гарантирует соответствие теме, не обращается к реальным моделям. Тема отображается заголовком. Подготовленные строфы выбираются по настроению и количеству. Тексты могут повторяться. Внутренние единицы не являются реальной валютой.

HTTP-адаптеры подготовлены по предварительным контрактам. Реальный backend отсутствует; его интеграция не протестирована. Unit-тесты с подставным fetch проверяют клиент, а не сервер. Тесты локальных адаптеров не подтверждают безопасность, конкурентность и транзакционную целостность будущего backend.

## Выполненные проверки

- Vitest: 19 сценарных тестов проходят (авторизация, генерация/списание, недостаток, компенсация, дедупликация, изоляция, администрирование, персистентность, восстановление, сбой хранения, конфигурация и HTTP-клиент).
- TypeScript strict: `npm run typecheck` — успешно.
- Production: `npm run build` — успешно, файлы в dist.
- npm после обновления Vitest до 5.1.1 сообщает 0 известных уязвимостей.
- В браузере проверены вход Анны; успешная генерация; копирование с подтверждающим уведомлением; перезагрузка страницы готового результата; принудительный сбой и возврат 10 единиц, включая обновление баланса и журнала после ухода со страницы обработки; переключение ADMIN/USER; начисление Михаилу 50 (баланс 10 → 60); отдельная история Михаила; мобильный кабинет и переход через меню при ширине 390 px. Ошибок/warnings в журнале проверенной вкладки не получено.
- Создание пользователя, запреты роли, повторный возврат, конкурентные повторы в одном runtime и перезагрузка незавершённой записи проверены автоматическими тестами. Полноценного E2E-набора и проверки всех браузеров нет.

## Следующий этап

Согласовать REST и жизненный цикл генерации; реализовать Python backend и PostgreSQL, серверную идентификацию/права, хеширование паролей, транзакционное списание/возврат, серверную идемпотентность и выполнение AI-задач. API-ключи хранить только на сервере. Согласовать cookies/CORS/CSRF, затем выполнить интеграционные и security/concurrency проверки и переключить VITE_DATA_SOURCE=http.
