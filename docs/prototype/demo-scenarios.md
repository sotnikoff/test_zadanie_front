# Демонстрация за 5–10 минут

1. На логине нажать «Сбросить демо-данные» и подтвердить.
2. Войти Анной: баланс 130, есть примеры стихов. Неверный пароль должен дать ошибку.
3. Создать стихотворение из двух строф: результат доступен сразу, баланс 120. Скопировать текст.
4. Найти генерацию и списание −10 в истории. Обновить страницу: данные сохраняются.
5. Показать начальную неуспешную генерацию Анны и связанный возврат.
6. Войти Михаилом: одна генерация уменьшает баланс с 10 до 0, следующая недоступна. Чужая запись по прямой ссылке не открывается.
7. Войти Алексеем: баланс 0, история пустая, генерация недоступна.
8. Выйти, сбросить данные и проверить восстановление балансов 130 / 10 / 0. Отмена подтверждения не должна менять данные.

Аккаунты и запуск — в [README](../../README.md). Это инструкция показа, не отчёт о выполненной ручной приёмке.
