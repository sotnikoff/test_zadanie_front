# Проверки и приёмка

## Что уже проверено

После удаления поллинга 25.11.2026: `npm run lint`, `npm run typecheck`, `npm run build` — успешно; `npm test` — 25/25. Тесты относятся к локальному API и HTTP-адаптеру с подставными ответами. Браузерная проверка этой правки не выполнялась. Текущая правка документации не запускает проверки заново.

Ранее вручную проверены вход, генерация, списание и сохранение результата после перезагрузки. Полная ручная приёмка не зафиксирована.

## Что проверить на backend

Все критерии ниже — проект приёмки, пока не подтверждённый для Django/PostgreSQL. Сначала используются автоматические интеграционные тесты с управляемым AI; затем — реальный провайдер и ручной проход интерфейса. На реальном AI проверяем тему, пожелания, настроение и число четверостиший по согласованным примерам Q-04; наличие текста само по себе не подтверждает качество. Одновременные операции проверяются отдельными соединениями PostgreSQL.

| ID | Проверка | Ожидаемый результат |
| --- | --- | --- |
| AC-001 | Вход и выход | Верный пароль допускает активного пользователя; неверный пароль, выход и блокировка исключают доступ. |
| AC-002 | Изоляция | Второй пользователь не получает чужие результаты, операции или баланс, включая прямые запросы по ID. |
| AC-003 | Генерация | При балансе 20 успешная генерация стоимостью 10 сохраняет текст, один DEBIT и остаток 10. |
| AC-004 | Валидация | Пустая тема, неверные параметры и ключ отклоняются до записи и списания. |
| AC-005 | Недостаток средств | При балансе меньше 10 нет списания и AI-вызова, даже если ранее quote разрешал запуск. |
| AC-006 | Атомарность | Ошибка БД при принятии откатывает генерацию, операцию и изменение кошелька вместе. |
| AC-007 | Возврат | Техническая ошибка AI даёт FAILED и один полный REFUND. |
| AC-008 | Одновременные списания | При балансе 10 из двух разных запросов принимается один; остаток 0. |
| AC-009 | Повтор генерации | Тот же ключ и параметры возвращают прежнюю запись без второго списания или AI-вызова. |
| AC-010 | Конфликт ключа | Другие параметры принятого ключа отклоняются без изменения данных. |
| AC-011 | Повтор возврата | Повторная и одновременная компенсация увеличивает баланс только один раз. |
| AC-012 | Обрыв соединения | Состояние восстанавливается по прежнему ключу без нового списания. |
| AC-013 | Падение сервера | Служебное восстановление завершает просроченную запись с одним возвратом, не затрагивая свежие. |
| AC-014 | Поздний ответ | Ответ после окончательного возврата не переоткрывает генерацию и не списывает снова. |
| AC-015 | Ошибка сохранения | Результат не сохраняется частично; фактически сохранённый успех не получает возврат. |
| AC-016 | Аккаунт | Создаются пользователь и кошелёк 0; email уникален, смена пароля и блокировка работают. |
| AC-017 | Начисление | При исходном балансе 0 сумма 30 создаёт CREDIT и баланс 30 с автором/комментарием; дробные и неположительные суммы запрещены. |
| AC-018 | Повтор начисления | Повтор формы не дублирует CREDIT; изменение параметров прежнего ключа даёт конфликт. |
| AC-019 | Начисление и списание | При одновременных действиях остаток совпадает с журналом, отрицательного баланса нет. |
| AC-020 | Права оператора | Без разрешений начисление недоступно; прямое изменение баланса и редактирование/удаление операций запрещены. |
| AC-021 | Итоги | Суммы и числа записей соответствуют фильтрам; возвраты учитываются своей датой, текущий баланс не зависит от периода. |
| AC-022 | Токены | Модель и известный usage сохраняются один раз; неизвестный расход — NULL; цена от токенов не меняется. |
| AC-023 | Интерфейс | История, фильтр, копирование и баланс работают; данные сохраняются после перезагрузки. Проверить ошибки, мобильный экран и клавиатуру. |
| AC-024 | Журнал | Суммы, остатки и связи с генерациями согласованы; расхождения обнаруживаются без переписывания истории. |
| AC-025 | Числовые границы | Дроби и переполнение отклоняются; начисление оставляет допустимый запас для возврата незавершённых генераций. |
| AC-026 | Запуск | Сервис запускается по инструкции с миграциями; перезапуск не теряет БД. |
| AC-027 | Эксплуатация | HTTPS, cookie/CSRF и хранение секретов проверены; резервная копия восстанавливается. |
| AC-028 | Нагрузка | Время ответа и число параллельных запросов проверены по согласованным значениям; сейчас пороги не заданы. |

При сдаче указать для проверенных критериев дату, коммит, команду/шаги и фактический результат. Неисполненные проверки и фактически затраченное время перечислить отдельно. [Требования](../product/requirements.md) · [Бизнес-правила](../product/business-rules.md).
